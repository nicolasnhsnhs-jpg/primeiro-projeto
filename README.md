# Jogo de Adivinhar o Número 🎯

É um jogo simples de adivinhar um número de 1 a 100.

## Como jogar

1. Tenha o Python instalado
2. No terminal, dentro da pasta do projeto, rode:

```
python jogo.py
```

## O que aprendi neste projeto

- ler entrada do usuário com input()
- Resolver uma quebra proposital
